# 觅露 (Truffle) v1.4.1

> 认知主权声明工具 — 在混沌繁杂的数据中，敏锐地捕捉那一点最有价值的认知。

## 核心功能

### 两种标记模式
- **猎人模式（划词摘录）**：选中网页文字 → 悬浮窗弹出「标记」→ 编辑保存
- **考古模式（全页摘录）**：按 `Alt + Shift + X` → 整页内容自动提取到编辑器

### AI 辅助功能
- **标题生成**：一键生成简洁中文标题
- **标签生成**：自动生成5个分类标签
- **内容总结**：提取3-5个核心要点
- **扩展阅读**：推荐3个深入阅读方向
- **批判性思考**：找出3个关键问题（逻辑漏洞、假设、偏差）
- **翻译**：全文翻译成中文
- 所有 AI 功能走后台异步队列，逐个执行，右上角显示实时进度（1/4, 2/4...）

### 保存方式
- **File System Access API**：直接写入用户选择的本地文件夹（推荐）
- **浏览器下载**：兼容模式，逐段保存确保内容不丢失
- 支持「扁平」和「按分类」两种文件夹组织方式

### 7个AI平台DOM提取优化
整页保留时自动检测并提取结构化对话内容：
豆包、Gemini、DeepSeek、Kimi、元宝、GPT、Sider

## 安装方法

### 开发者模式加载（Chrome/Edge）

1. 下载本项目代码
2. 打开 Chrome/Edge 扩展管理页面：`chrome://extensions/`
3. 开启右上角「开发者模式」
4. 点击「加载已解压的扩展程序」
5. 选择本项目的根目录（包含 `manifest.json` 的文件夹）

### 快捷键
- `Alt + Shift + X` — 唤起全页标记（考古模式）

## 使用流程

### 首次使用
1. 点击扩展图标 → 打开设置页面
2. 输入**激活码**（内测版需向开发者索取）
3. （可选）配置 AI API Key
4. （可选）选择保存文件夹

### 猎人模式（划词摘录）
1. 在网页中选中一段文字
2. 悬浮窗弹出 → 点击「标记」
3. 在编辑器左列填写/生成标题、标签、分类
4. 在编辑器右列填写个人思考
5. 勾选需要的 AI 辅助功能（可多选：总结/扩展/批判/翻译）
6. 点击「保存到本地」→ AI 后台自动运行，右上角显示进度

### 考古模式（全页摘录）
1. 按 `Alt + Shift + X` 或点击扩展图标
2. 整页内容自动提取到编辑器
3. 编辑、勾选 AI 功能
4. 保存

## 技术栈

- Chrome Extension Manifest V3
- Vanilla JavaScript（原生，无框架依赖）
- File System Access API / chrome.downloads API
- 双重超时保护：循环内时间检查 + maxChunks 硬限制
- Service Worker 保活：chrome.alarms keepAlive
